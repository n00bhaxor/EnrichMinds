This material has been gathered, coalated, revised, refined, and printed for use as teaching aids for our non-profit, which helps high school-level students with entry level cyber security concepts ranging from "WTH is Linux" to cracking WPA keys. All material has been used strictly in an educational atmosphere. Any illustrations included with the material are able to be used with said material.

We are releasing this material as an instructional aid. It is meant solely as supplemental material and is not meant to replace any standardized curriculum or other teaching aid.
